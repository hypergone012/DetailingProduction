# Онлайн-запись для студий детейлинга

Белый (white-label) сайт-приложение: **один код → много студий**.

- Клиент записывается с телефона или компьютера.
- Владелец ведёт день, календарь боксов, клиентов, цены и оплаты в кабинете.
- Сайт ставится на телефон и ПК как приложение (PWA).
