- `.env.example`: browser-safe (`VITE_*`) отдельно от server-only.

Проверки: `pnpm test` — **46 passed** (+ расшифровка push ключом подписчика, VAPID-подпись, ICS, тексты, токены); `pnpm test:api` — **15 passed** через реальный HTTP (gateway → Deno handler → PostgREST → Postgres/GoTrue/Storage), включая **реальную доставку зашифрованного Web Push по HTTPS** на локальный push-сервис (расшифровка, 410 → отключение подписки, без повторной отправки, demo — ничего не отправляет); `pnpm functions:check` (deno check) — OK.

На маскируемом значке (Android) она целиком помещается в безопасную зону 80 % — на телефоне выглядит как макет, без рамки (фон — средний цвет края картинки). Логотип на прозрачном фоне обрезается по рисунку и ставится по центру на фон темы студии. Фото заполняет значок целиком.

### Срочно: вкладки «Запись», «Гараж», «История» открывались медленно (2026-10-03, по жалобе владельца)

**Причина найдена и воспроизведена.** Переход между экранами (`ScreenTransition`) ждал, пока старый экран доиграет анимацию ухода (`AnimatePresence mode="wait"`). При этом в уходящую обёртку уже подставлялось содержимое новой страницы. Если в нём был элемент с общей layout-анимацией (подложка категорий на «Услугах», переключатель оформления в «Профиле»), уход не завершался. Экран оставался прозрачным, все следующие вкладки застревали так же. В Chromium-тесте экран не появлялся и через 20 с.
