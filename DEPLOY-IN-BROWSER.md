# Как запустить сайт: только браузер, без программ

В итоге у вас будет обычный сайт с адресом вида `https://detailing-studio.pages.dev`:

- **клиенты** записываются на `…/s/graphite/`;
- **владелец** работает в кабинете `…/s/graphite/owner/`.

Сайт открывается на телефоне, планшете и компьютере. Его можно установить как приложение — иконка на главном экране (см. часть 5).

Понадобятся три бесплатных аккаунта:

| Сервис | Что делает | Цена на старте |
|---|---|---|
| **Supabase** | API и база: записи, клиенты, вход владельца, фото, уведомления | бесплатный план |
| **Cloudflare** | хостинг самого сайта | бесплатно |
| **GitHub** | здесь лежит код; кнопка «Run workflow» выкладывает всё сама | бесплатно |

> **Важно про бесплатный Supabase.** Проект на бесплатном плане засыпает, если им неделю никто не пользуется. Его можно разбудить в панели Supabase, но для настоящей студии берите план Pro.

Время: около 15 минут, из них 10 — сам запуск.

---

## Часть 1. Supabase — API и база (5 минут)

1. Откройте **supabase.com** → **Start your project** → войдите через GitHub.
2. **New project**:
   - **Name** — любое, например `detailing`;
   - **Database Password** — нажмите **Generate a password** и **сохраните пароль**, он понадобится в шаге 4. Удобнее всего пароль только из латинских букв и цифр: если сгенерировался со знаками `@ : / ? #`, сгенерируйте ещё раз;
   - **Region** — ближайший к клиентам, для России — **Central EU (Frankfurt)**;
   - нажмите **Create new project** и подождите 1–2 минуты.
3. **Project ref** — это 20 латинских букв в адресе страницы проекта: `supabase.com/dashboard/project/`**`abcdefghijklmnopqrst`**. Его же показывает **Project Settings → General → Project ID**. Скопируйте.
4. **Строка подключения к базе:**
   - вверху страницы проекта нажмите **Connect**;
   - выберите **Session pooler**: именно его, а не «Direct connection»;
   - скопируйте строку вида `postgresql://postgres.abcd…:[YOUR-PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:5432/postgres`;
   - **замените `[YOUR-PASSWORD]`** на пароль из шага 2, квадратные скобки тоже убрать.
5. **Токен доступа:** аватар справа вверху → **Account preferences** → **Access Tokens** → **Generate new token** → любое имя → скопируйте токен. Он показывается один раз.

## Часть 2. Cloudflare — хостинг сайта (3 минуты)

1. Зарегистрируйтесь на **dash.cloudflare.com** и подтвердите почту.
2. **Account ID:** откройте **Workers & Pages** (или главную страницу аккаунта). Справа будет **Account ID** — скопируйте.
3. **API-токен:**
   - справа вверху: значок профиля → **My Profile** → **API Tokens** → **Create Token** → внизу **Create Custom Token**;
   - **Token name:** `deploy`;
   - **Permissions:** `Account` → `Cloudflare Pages` → `Edit`;
   - **Account Resources:** `Include` → ваш аккаунт;
   - **Continue to summary** → **Create Token** → скопируйте токен.

## Часть 3. GitHub — положить ключи (3 минуты)

Откройте репозиторий: **github.com/hypergone012/DetailingProduction** → **Settings** → слева **Secrets and variables** → **Actions** → **New repository secret**. Добавьте по одному:

| Name (точно так) | Значение |
|---|---|
| `SUPABASE_PROJECT_REF` | Project ref из части 1, шаг 3 |
| `SUPABASE_DB_URL` | строка подключения из части 1, шаг 4, **с вашим паролем** |
| `SUPABASE_ACCESS_TOKEN` | токен из части 1, шаг 5 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из части 2, шаг 2 |
| `CLOUDFLARE_API_TOKEN` | токен из части 2, шаг 3 |
| `DEMO_OWNER_PASSWORD` | придумайте пароль от 8 символов: с ним владельцы демо-студий входят в кабинет |
| `LLM_API_KEY` *(необязательно)* | ключ Anthropic API для умного помощника. Без него помощник отвечает по шаблонам |

Секреты видны только сервису выкладки. В журнал выкладки они не попадают: даже в публичном репозитории значения скрыты звёздочками.

## Часть 4. Запуск (одна кнопка, ~10 минут)

1. В репозитории откройте вкладку **Actions**. Если GitHub спросит — нажмите **I understand my workflows, go ahead and enable them**.
2. Слева выберите **Deploy** → справа **Run workflow**:
   - **Branch** — оставьте как есть;
   - **Имя проекта Cloudflare Pages** — латиница, цифры, дефис, например `detailing-studio`. Адрес сайта будет `https://detailing-studio.pages.dev`, а если имя занято, Cloudflare добавит хвостик (`detailing-studio-1x2.pages.dev`) — итоговый адрес будет в отчёте;
   - **Свой домен** — пока пусто;
   - зелёная кнопка **Run workflow**.
3. Через ~10 минут у запуска появится зелёная галочка. Откройте его: внизу страницы, в разделе **Summary**, — таблица со ссылками на сайт и кабинет каждой студии.

Что делает кнопка:

- база: таблицы, защита данных, расписания уведомлений;
- серверные функции и ключи (генерируются один раз и хранятся в Vault);
- вход владельцев и студии из папки `tenants/`;
- сборка сайта и выкладка в Cloudflare;
- в конце — проверка опубликованного сайта.

Повторный запуск безопасен. Он обновляет сайт и не трогает записи, клиентов, оплаты и сгенерированные ключи. Запускайте его после каждого изменения кода или студий.

**Если запуск красный.** Откройте его и нажмите на шаг с крестиком: в конце будет понятное сообщение, например «Не заданы секреты: …» или «включите Legacy API keys». Если причина непонятна, пришлите мне ссылку на запуск — я прочитаю журнал и исправлю.

## Часть 5. Как «скачать» приложение на телефон и компьютер

Отдельного файла для скачивания нет — **приложение и есть сайт**. Его ставят прямо из браузера, без App Store и Google Play: на телефоне появляется иконка студии, открывается без адресной строки, как обычное приложение. Обновляется само.

**Где владелец берёт ссылку и QR-код:** кабинет → **Студия** → **«Ссылка для клиентов»** (или значок QR на экране «Сегодня»). Там:

- **Скопировать** — ссылка в буфер обмена, чтобы отправить в WhatsApp или Telegram;
- **Поделиться** — на телефоне сразу открывает список мессенджеров;
- **Скачать QR (PNG)** — картинка с QR-кодом, названием студии и адресом, для печати на стойку или визитку;
- инструкция по установке для клиентов и для вас.

![Ссылка и QR-код в кабинете](docs/images/owner-share-phone.png)

**Установка на устройство:**

| Устройство | Как установить |
|---|---|
| **iPhone / iPad** | открыть ссылку в **Safari** → кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран „Домой“»** → **«Добавить»** |
| **Android** | открыть ссылку в **Chrome** или **Яндекс Браузере** → меню **⋮** → **«Установить приложение»** или **«Добавить на главный экран»** |
| **Компьютер** | **Chrome / Edge / Яндекс Браузер:** значок установки справа в адресной строке или меню → **«Установить»**. **Safari на Mac:** «Файл» → «Добавить в Dock» |

![Инструкция по установке в кабинете](docs/images/owner-install-steps.png)

Клиент видит такую же подсказку на сайте в разделе **«Профиль»**. Если браузер умеет ставить приложение в один клик, там будет просто кнопка **«Установить»**.

![Карточка установки у клиента](docs/images/client-install-card.png)

**Кабинет владельца** ставится отдельным приложением: откройте `…/s/<студия>/owner/` и сделайте то же самое. На iPhone уведомления о новых записях приходят **только в установленное приложение** (iOS 16.4+) — так устроен Safari.

**На компьютере** сайт открывается в полноценной версии: меню сверху, две колонки на главной, календарь кабинета с боковой панелью.

![Сайт на компьютере](docs/images/client-desktop.png)

## Часть 6. Свой домен (по желанию)

1. Cloudflare → **Workers & Pages** → ваш проект → **Custom domains** → **Set up a custom domain** → например `zapis.vash-domen.ru`. Следуйте подсказкам: проще всего, если домен тоже обслуживает Cloudflare.
2. GitHub → **Actions** → **Deploy** → **Run workflow**, в поле **«Свой домен»** укажите `https://zapis.vash-domen.ru`. Кнопка перенастроит вход, уведомления и CORS на новый адрес. После этого сервер отвечает только новому адресу, поэтому дальше давайте клиентам его.

## Часть 7. Перед приёмом настоящих клиентов

- **Настоящая студия.** Своя папка в `tenants/` (см. `CLONE-IN-6-MINUTES.md`), реальные фото, телефон и адрес. Переход в рабочий режим — кабинет → **Студия** → **Режим работы**.
- **Почта для владельцев (SMTP).** Supabase → **Authentication** → **Emails** → **SMTP Settings**: подключите почтовый сервис (Яндекс 360, Mail.ru для бизнеса, Unisender, Resend). Без этого письма «Забыли пароль?» уходят только адресам участников вашей команды Supabase.
  - Ссылки установки пароля для новых владельцев **не печатаются** в журнал GitHub: репозиторий публичный.
- **Доступность из России.** Проверьте сайт и запись с мобильного интернета **без VPN**. В 2025 году сообщалось о блокировках и замедлениях доменов `supabase.co` и Cloudflare у части российских провайдеров. Из этой среды проверить это нельзя. Если не открывается:
  - сайту помогает свой домен (часть 6);
  - для API у Supabase есть платная опция Custom Domain.
- **Оплата Supabase Pro**, чтобы проект не засыпал.

## Что проверено, а что нет

**Проверено в среде разработки:**

- весь код, тесты и сборка;
- шаги выкладки, которые работают с базой: на локальном Postgres с заменителем Vault — первый запуск создаёт ключи, второй их не меняет;
- функции: Supabase CLI 2.119.0 собрал все четыре и остановился только на сетевом запрете;
- синтаксис самой кнопки: actionlint.

**Не проверено:** настоящая выкладка в Supabase и Cloudflare — из среды разработки нет доступа к их API.

Первый запуск у вас — первый настоящий. Если что-то упадёт, пришлите ссылку на запуск.
